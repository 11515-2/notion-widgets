# notion-widgets

给 Notion 用的一组极简小组件：**黑白色 · Material You 形态 · 自动深浅色 · 铺满容器**。

纯静态 HTML/CSS/JS，无构建步骤、无框架、**不含任何密钥**。

## 组件

| 组件 | 地址 | 说明 |
|:--|:--|:--|
| 总览 | `/all/` | 时钟 + 天气 + 倒计时 + 今日一句，四块一屏 |
| 时钟 | `/clock/` | 实时时间 + 秒 + 日期 + 农历 + 距下个重要节日 |
| 天气 | `/weather/` | 大同 / 苏州可切换，数据来自 Open-Meteo |
| 倒计时 | `/countdown/` | 默认高考，支持自定义日期与标题 |
| 今日一句 | `/quote/` | 数据来自今日诗词接口，半小时一句，接口挂了落回本地句池 |

## 嵌入 Notion

1. 在 Notion 页面输入 `/embed`，粘贴组件地址
2. 点 embed 右上角 `⋮⋮` → 选 **Full width**
3. 拖 embed 右下角手柄调高度

**推荐尺寸**（组件按容器宽高比自动切排布，拖成什么比例就走对应那一档）：

| 想要的效果 | 宽 × 高 |
|:--|:--|
| 竖版：上两块并排 + 下两块通栏 | 400 × 560 |
| 一大三小：时间块跨两行当主角 | 710 × 400 上下 |
| 四块横排一行 | 700 × 320 |

Notion 新插入的 embed 默认只有 320×110，那个尺寸装不下全部字段，必须先拖大。

## 参数

**主题**（透明背景下必给，否则可能白字白底）：

```
?theme=dark
?theme=light
```

**倒计时自定义**：

```
/countdown/?date=2027-06-07&label=高考
/countdown/?date=2027-09-01&label=开学
```

**天气城市**：地址后加 `?city=sz` 切苏州（默认大同），界面上不占位置。
城市坐标在 `weather/index.html` 的 `CITIES` 里改。

**实心卡片**：加 `&solid=1`（默认背景透明，跟着宿主页面走）。

## 字体

**Maple Mono NF CN**，OFL-1.1。取 [maple-font](https://github.com/subframe7536/maple-font) v7.9 的
Regular / Bold 两个字重，按组件实际用到的 600 来个字符**子集化**成 woff2（两个文件合计约 288KB），
本地托管在 `assets/fonts/`——不依赖访客设备有没有装这个字体。

- 全局字重 `600`，主数字与正文 `700`（真 Bold 字重，不是浏览器合成粗体）
- 字体族优先 `Maple Mono NF CN Web`（托管那份），回落到本机安装版、再回落系统等宽
- 许可全文见 `assets/fonts/OFL.txt`；OFL 要求分发时一并附带，别删

## 农历

时钟里的日期自带农历（形如 `2026.10.31 周六　九月廿二`），由 `assets/lunar.js` 纯前端离线算，
覆盖 1900–2099，无任何网络请求。

⚠️ 数据表与算法出自 lunar project（Fung F. Lee / Ricky Yeung，GPLv2，原始历法数据来自香港天文台），
已在文件头写明。自用没问题；**将来若要把这些组件并进别的协议的项目，先确认 GPLv2 的兼容性**。
算法已用 Python `lunardate` 对 405 个日期（2026 整年 + 若干边界年）做过交叉验证，结果全一致。

## 设计规范

- 颜色：只有黑白灰，不出现任何色相
- 背景：外框透明，块面用半透明遮罩（浅色 `rgba(0,0,0,.055)`、深色 `rgba(255,255,255,.085)`），叠在什么底色上都融得进去
- 圆角：面板 `12px` / 面板内 `6px`，无边框
- 间距：4px 基数，段间距与段内间距保持 4:1 以上
- 数字：等宽字体 + `tabular-nums`，秒数跳动时宽度不变
- 深浅色：跟随系统 `prefers-color-scheme`，可用 `?theme=` 覆盖
- 尺寸：全部 `clamp()` + `vh/vw/vmin`，跟着容器缩放；布局按 `aspect-ratio` 分档，不按宽度

设计变量全部集中在 `assets/base.css` 的 `:root`，改一处全局生效。

## 关于密钥

本仓库**不含任何密钥**。两个外部接口都是免费公开的，无需注册、无需密钥，
响应头都带 `access-control-allow-origin: *`，可直接在浏览器里请求：

- **天气** — [Open-Meteo](https://open-meteo.com/)
- **今日一句** — [今日诗词](https://www.jinrishici.com/doc/) `GET https://v1.jinrishici.com/all.json`
  （若接口不可用，自动落回内置的本地句池，界面不会空）

时钟、倒计时、农历、节日倒计时全部在浏览器本地算，农历数据表内置在 `assets/lunar.js`（1900–2099）。
