notion-widgets

黑白 · Material You 形态 · 自动深浅色 · 一个 iframe 一个组件

总览 · 四合一 时钟 + 天气 + 倒计时 + 今日一句，2×2 一屏看完 时钟 实时时间 + 秒 + 日期 + 农历 天气 大同 / 苏州可切换，Open-Meteo 数据 倒计时 默认高考，支持 ?date= 自定义 今日一句 本地句池，一天一句，稳定不重复
嵌进 Notion：输入 /embed → 粘贴组件地址 → 拖动调整高度。
背景是透明的，文字色要跟 Notion 页面主题走：深色页面加 ?theme=dark，浅色页面加 ?theme=light。
想要实心卡片：再加 &solid=1。
倒计时可带参数：countdown/?date=2027-06-07&label=高考
天气切苏州：weather/?city=sz
总览建议高度 460px 以上（宽 660 以上最好看）。
所有组件都没有任何 API key，天气走 Open-Meteo 公开接口。
